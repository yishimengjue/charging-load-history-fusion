# v0.4已确认勘误

这些修改不依赖新消融结果。

1. LCL表遗漏神经单分支。原保存预测的三个种子分别评分后平均，2013年11月、12月、2014年1月的神经MAE为0.156419、0.143747、0.156262，合并0.152106。平均预测对应0.159425、0.146679、0.160666，合并0.155519。神经单分支合并低2.19%，不能用平均相对两树组合的改善证明平均优于组成分支。
2. 损失不是与MAE相差一个加性常数。观测标签的训练尺度均值为s_bar时，完整损失=(0.95 MAE_actual+0.05 MAE_empty)/s_bar，神经预测未经非负截断。最终F的MAE不属于该训练目标。
3. AMS历史区间起点为t-168至t-1，目标区间起点为t至t+23；OP/LCL历史记录时间戳为t-167至t，目标时间戳为t+1至t+24。统一24步索引可以保留，物理时间映射须分别写出。
4. AMS条件读取融合已有结果3.148614 kWh，应补入比较表。“共享树”和“两树组合”在单序列AMS中不设跨对象对照，不笼统写“未列”。
5. 条件读取消融仍属旧结构；当前结构的历史摘要增量由本轮匹配重新训练检验，未完成之前不引用旧消融作为替代。

v0.4和旧实验保持原样，v0.5采用这些修改并纳入本轮完成后的消融。只交付已完成渲染检查的Word，不把中间模板作为最终稿。
