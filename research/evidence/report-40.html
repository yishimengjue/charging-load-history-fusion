# 7月一次性验证：新方案更准，但尚不足以支撑顶刊结论

日期：2026-09-30。用户明确授权后，完成预先冻结的7月验证与只读复核。

## 1. 总体结论

**新方案相对原F，平均绝对误差降低7.66%；相对固定Chronos参考，降低17.62%。**
此前的改进不只出现在开发期，现已得到一个同来源、25天后续时间段的正向确认。
这支持保留新方案作为工程基线，但不能据此认定具备顶刊创新或跨数据集泛化能力。

## 2. 这次到底改了什么

```text
原F：历史负荷直接预测未来24个小时边界的功率
                    |
          +---------+---------+
          |                   |
   不再整天丢弃零散真值     显式告诉模型星期几
   只用已观测、已到期值     UTC起报星期的7列编码
          |                   |
          +---------+---------+
                    |
        新方案 C_weekday：保留原预测主干
                    |
          固定模型，验证7月1至25日
                    |
             MAE降低7.66%
```

这是“更充分利用已有真实数据 + 补足日历信息”，不是把缺失值编造出来，
也不是新加会话分解、价格、门控或Chronos融合。此处A/C是本轮实验臂名称，
不等同于最早ACN会话实验里的同名路线。

## 3. 同一批样本上的结果

以下五个方案均在相同4,775个已观测目标点上评分。MAE表示平均差多少kW；
RMSE对大误差更敏感，两者越低越好。改善率为“基线误差减去新误差，再除以基线误差”。

| 方案 | 改动 | MAE / kW | RMSE / kW | 相对原F的MAE降低 |
|---|---|---:|---:|---:|
| 原F（A） | 仅保留目标完整日的训练标签 | 3.8468 | 8.6287 | 基线 |
| C | 加入不完整日中已有的真实标签 | 3.6964 | 8.4091 | 3.91% |
| A_weekday | 原F加星期 | 3.7035 | 8.3450 | 3.72% |
| **C_weekday** | **真实标签利用 + 星期** | **3.5522** | **7.8879** | **7.66%** |
| Chronos-P50 | 固定预训练模型参考 | 4.3117 | 9.6933 | 不属上述消融 |

新方案相对原F的RMSE降低8.59%；相对C再降低MAE 3.90%。
新方案相对Chronos的MAE/RMSE分别降低17.62%/18.63%，仅指本次固定配置和评价范围。

| 时间段 | 新方案相对同期原F的MAE降低 | 证据性质 |
|---|---:|---|
| 2022年1至3月 | 4.65% | 已反复探索的开发期 |
| 2022年7月1至25日 | 7.66% | 模型冻结后的短期时间确认 |

**4.65%与7.66%不能相加。** 不同时间段的难度和训练库存不同；旧4至6月最终结果保持原样，
没有用本候选重新预测后替换。7月数值现已看过，后续不能再称为未见测试集。

## 4. 必须同时看到的限制

| 检查项 | 事实与解释 |
|---|---|
| 各编号 | 9个可评价编号相对原F均改善；10、11无支持，仍保留在覆盖统计中 |
| 各日期 | 25天中23天改善；7月19日、22日分别退步3.29%、0.37% |
| 局部退步 | 相对上一版C，编号8退步0.43%；加星期并非所有子集都获益 |
| 稀疏编号4 | 仅102点、无完整目标日，却贡献约40.29%的总绝对误差下降；不删去，也不夸大稳定性 |
| 平均偏差 | 新方案为-1.2878kW，原F为-1.3385kW；仍整体低估，且低估幅度大于Chronos的-0.7588kW |
| 起报覆盖 | 275个候选“编号×日”中起报217次，216次可评分；145次拥有完整24个目标点 |
| 缺失真值 | 只能评价已观测点，不能推断全天、全部编号或未观测工况都改善 |
| 数据口径 | Optimise Prime Table27的小时边界附近实测kW快照，不是小时平均功率或电量，也不是原ACN的15分钟会话任务 |
| 验证强度 | 仅25天、同来源；原始文件字节和时间元数据此前已取得，不声称任何主体都未接触过该数据 |

主比较的绝对MAE下降为0.2946kW。预定7日/14日块重采样区间分别为
[0.2006, 0.3912]与[0.2575, 0.3334]kW，均为正；但25天难以充分表征时间依赖，
这些仅作短样本不确定性诊断，不作稳健显著性或外部验证结论。Chronos预训练重叠也未排除。

昨天/上周复制基线分别只能在3,366/2,811个共同点上比较，新方案MAE降低36.11%/22.87%。
这些样本不同，不与上方4,775点主表混排名次。

## 5. 执行与复核

- 解封前固定36个F检查点，训练只用截至2022年7月1日起报时已开放、已到期的标签；本次解封后没有F重训或调参。
- 新开放4,806个功率值，逐个与原来源复核；其中31个因历史起报条件不满足而不进入评分，另82个后续截断日记录仍封存。
- 只读复核通过275个窗口、36个F检查点、217条Chronos曲线、943行指标和4,000次重采样；首日F与解封前预测完全一致。
- 本轮729项测试通过，含7项新增验收测试。独立窗口与标量指标路径用于交叉检查，但共享部分解析/特征/Chronos组件，且为同一执行者，不称外部独立审查。
- 原快照、旧最终结果及冻结证据不变；7月访问标记保留，禁止删除后重跑盲测。旧交接ZIP未更新。

## 6. 下一步取舍

**先沉淀C_weekday基线，不因为一次正结果继续叠模型。** 本次回答了“已有改进是否在后续短期仍有效”，
尚未回答“跨站点/数据源是否有效”“缺测带来的评价偏差如何解决”“价格怎样影响负荷”。

1. 下一轮先明确独立验证来源及目标口径，优先连续实测功率；不能把剩余82个截断日记录包装成新的充分验证集。
2. 若继续研究方法，将“观测不完整时如何有效学习，并诚实评价适用范围”作为待验证问题，而不是把加星期、恢复标签直接称为新算法。先与强简单基线和相关研究对齐，再决定是否需要新模块。
3. 价格研究保持独立边界：需要实际价格变化、当时可获信息与混杂因素证据；本次未识别价格效应，不能从预测提升反推出价格因果关系。

当前定位：**有可复核的预测改进和更强基线，尚不足以宣称顶刊投稿准备完成。**
每小时心跳继续按原设置只读提醒，不重建、不重置计数，也不自动授权新实验。
