# 会话分解：瓶颈验证与实际预测结果

2026-10-20。已制定方案并执行，不是待运行计划。

## 1. 结论

**会话结构有单站预测收益，但当前候选不能替换双站强基线。后续若继续会话
路线，应先检验整日到达过程的可预测性，而不是继续调整单车电量或堆叠融合模块。**

- Caltech：联合会话响应辅助直接预测，MAE从8.7410降至8.4626，降低3.19%。
- JPL：同一设计从10.2238升至10.6182，增加3.86%。不得只报告成功站点。
- 在会话期望模型内部，保留电量与持续时间配对比打散关系更准，但仍未超过
  直接预测强基线。这说明部件改善不等于最终路线胜出。
- 真值替换提示到达轨迹是当前会话模型的重要瓶颈，不是已经实现的精度提升，
  也不说明到达轨迹一定能从已有历史中预测出来。

## 2. 数据、任务与比较范围

采用原ACN导出会话及冻结特征，Caltech/JPL，午夜起报，未来96个连续15分钟格。
正式预测从2019-09-30开始，主评分2019-10-01至2020-02-29。主样本分别为
152天/14,592点和151天/14,496点。JPL最后一天只有65个有真值格，另列所有
有真值格指标，不补齐最后31格，也不让oracle决定实际模型的评分样本。

**这些日期已被查看；标签是会话恒功率代理，不是实测功率。** 本次不能确认
独立泛化、真实计量精度或论文创新。与最早A/B复核表的口径不同，不拼接提升率；
也不与Optimise Prime的4.6270 kW跨数据比较。

## 3. 实际预测：做了什么，提升多少

先用起报前已完成的会话建立“到来一辆车后，各时段平均贡献多少负荷”的响应核。
历史事件来自之前7日的已导出连接记录，未来事件使用原样本外到达预测。会话标记
使用近90日已完成记录，不足时回退历史池；分为工作日/周末和四个到达时间块。
每个训练样本都按其自己的起报时刻重建，不用今日的最终记录回填过去。

I保持相同的电量、时长和格内偏移边际，但令电量与“时长、偏移”独立；J保留
原配对。两者均解析计算期望，不做随机模拟。HI/HJ把相应的新到达负荷及历史
到达残余负荷两个特征交给P50负荷回归器，参数、训练行与树数相同。

| 方案 | Caltech MAE / kW | JPL MAE / kW |
|---|---:|---:|
| M3：既有强直接预测，含4小时到达记忆 | 8.7410 | 10.2238 |
| HI：M3 + 独立会话响应 | 8.6147 | 10.4600 |
| HJ：M3 + 联合会话响应 | **8.4626** | **10.6182** |
| I：独立会话期望曲线，直接叠加 | 9.5214 | 12.2788 |
| J：联合会话期望曲线，直接叠加 | 9.1854 | 10.8587 |

J相对I的MAE下降3.53%/11.57%，但两站都未超过M3。I/J输出条件期望，不是P50，
只能作为机制与期望曲线参照，不能把统计目标差异隐藏为架构优劣。

HJ相对HI在Caltech再降低1.77%，在JPL增加1.51%。新增会话历史监督不在M3的
全部输入中，因此M3到HJ不能全归因于配对机制；HJ对HI才是本轮同信息机制对照。

| MAE改善差值，正数为HJ较好 | 7日块95%区间 / kW | 14日块95%区间 / kW |
|---|---|---|
| Caltech，M3减HJ | [0.1537, 0.4479] | [0.1598, 0.4267] |
| Caltech，HI减HJ | [0.0691, 0.2533] | [0.0873, 0.2372] |
| JPL，M3减HJ | [-0.9354, 0.0364] | [-0.9690, 0.0377] |
| JPL，HI减HJ | [-0.5342, 0.1306] | [-0.5072, 0.0939] |

Caltech五个月的HJ均优于M3；JPL只在10月、1月改善。JPL均值退步，区间跨零，
不是已证实有害。区间按日相关性分块、未作多比较校正，均为探索性证据。

## 4. 诊断：误差更可能卡在哪里

下面故意使用未来真值，只回答“某环节若已知，会怎样”，不能部署或计作模型收益。

| 在J会话期望模型上替换的信息 | Caltech MAE | JPL MAE |
|---|---:|---:|
| 不替换 | 9.1854 | 10.8587 |
| 只知道真实跨日剩余负荷 | 8.7092 | 10.7712 |
| 知道整条真实到达计数轨迹 | 7.1526 | 5.6061 |
| 到达轨迹与跨日剩余负荷均已知 | 6.4057 | 5.5138 |

完整到达轨迹的条件改善为22.13%/48.37%，只修跨日部分为5.19%/0.81%。
这与过去“只给目标15分钟真实到达数”的辅助特征试验不同：本次让此前各时段
到达车辆的持续贡献进入后续负荷。不是推翻旧试验，也不是比较同一个oracle。

**评分后补充定位，明确不是预注册主检验：** 保留预测的日内分配，仅把日到达
总量替换为真值，MAE降至8.2373/7.0377，即下降10.32%/35.19%。再替换整条时段
分配，降到上表7.1526/5.6061。说明当前模型的总量和时段分配均值得检查；这种
先后替换是顺序相关的诊断，不是唯一、可相加的因果贡献，也不是精度上界。

另固定真实正贡献会话成员及精确到达时刻，统一加真实跨日贡献：

| 电量和持续时间条件 | Caltech MAE | JPL MAE |
|---|---:|---:|
| 电量和持续时间使用独立历史分布 | 7.3537 | 7.9012 |
| 真实电量、历史持续时间 | 7.3647 | 7.4983 |
| 历史平均电量、真实持续时间 | 7.0287 | 7.2810 |
| 真实电量、真实持续时间 | 约0 | 约0 |

只修一个会话标记没有带来与完整到达替换同等的改善；但这些条件实验所知的信息
不同，不能据此声称电量没有用。全真值约零只是重构代理标签的恒等式验收。
最大重构差分别为9.30e-11和8.22e-11 kW，不是可实现的预测精度。

跨日会话贡献占目标能量6.33%/0.17%，7日以前到达的贡献为0.00336%/0%。
新到达与跨日误差的MSE交叉项分别为+0.3405/-0.0429 kW²，不能预设误差必然
同向放大；这也不是旧B所有部件的完整误差归因。

## 5. 旧实现确实发现的问题

- 到达模型的arr_lag1在历史最后96行全部可见，在日前96个预测格中只在第1格可见。
- 旧历史筛选按到站而非最终记录完成。35个周度时点中，Caltech有34次含尚未
  满足释放规则的正贡献记录，单次最多7条；JPL为6次、最多1条。尚未量化其MAE影响。
- 跨日补偿将前6小时按缓冲坐标0—23传入条件电量分组，不是实际晚间时段72—95。
- 旧分配函数不适合任意窗口外区间；但保存的G6已有右侧缓冲，且左侧采用平移坐标，
  不能把未缓冲或负起点合成案例的误差直接归给保存的G6成绩。
- 旧idle预测没有进入充电功率轨迹；旧三因素诊断的电量比已包含到达数量，继续
  乘到达数量比会重复计算。不能直接采用它输出的“主要根因”。

以上是源码与合成证据。本轮新I/J也不是旧GMM模型逐项修补的复现，不能用它们
与早期B的分数差宣称修复贡献。

## 6. 去留决定与下一验证链

事前门槛为：HJ在两站都比M3和HI降低至少1% MAE，且7/14日块改善区间下界
均大于0。**未通过，因此停止扩展本轮响应特征原型，不追加窗口、分组或树数搜索。**
1%是资源投入门槛，不是期刊标准；不事后改成只要求Caltech成功。

若继续会话路线，下一个候选应只问：**预测“全天来多少辆 + 各时段如何分配”，
能否比当前逐时段到达预测更准，并把改善传到总负荷MAE？** 先做同历史、同预算
的到达预测对照，再固定响应结构测试总负荷；只有真实预测胜过M3才继续。
这不是本轮已经实现的结果，也不证明分层到达预测是新方法。

当前仍保留直接预测作为必须超过的基线。不按已见站点设置赢家切换，不自动启动
新的训练或解封；若再验证，应补起报可知事件和同口径实测负荷，而非继续在代理
标签上循环寻找参数。
