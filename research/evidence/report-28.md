# 固定主线与组件消融

日期：2026-11-04。状态：completed_verified。

## 主线

**S：历史统计预测 + L5：近期曲线与历史摘要融合 -> 各占50%。**

S使用LightGBM；L5使用TimeXer近期168小时编码、历史池读取和编号输出头。
历史摘要来自7天近期、28天同星期、84天同星期三个参照池，每池9项统计。
L5训练损失由95%有摘要任务和5%无摘要任务组成；预测时使用实际可获得的摘要。
预测目标为未来24个小时边界的功率快照，单位kW。

主线版本已锁定，不因本轮消融结果重新选参数、替换模型或改组合比例。

## 结论

1. **保留两路预测。** 完整主线相对单独S降低MAE 5.05% / 0.99%；相对单独L5降低2.13% / 3.17%。两路组合是当前结果的主体。
2. **保留历史摘要与学习读取。** 相对移除L摘要的对照，一至三月MAE降低2.18%；相对均匀读取降低1.69%。七月学习读取与均匀读取只差0.000101 kW，近于持平。
3. **编号头与5%辅助是补充。** 编号头相对无适配对照降低0.08% / 0.99%；5%辅助相对原组合降低0.11% / 0.29%。不把小幅增量写成主体收益。
4. **月份差异值得用于下一步组合验证。** 一月L5单独为4.746716，低于完整组合4.762217；二月完整组合4.960502，低于单独S的5.111102和L5的5.145277。三月去掉S或L的摘要分别为3.825037、3.828053，均低于完整主线3.856945。总体有效不等于每月每个组件都有收益。

上述收益均以被比较方法的MAE为分母；网页消融表中的“移除后上升”以完整主线为分母，百分比因此不同。各组件增益不能相加。

## 本轮新增与核对

只新增“均匀读取 + 5%辅助”这一项匹配训练：四个月、三个种子，共12个编码器及12组编号头。其他消融复用已核验预测，或在同一行上按50%组合。

均匀对照保持摘要、近期编码、门控、编号头、训练标签、80/20轮、学习率、batch64和训练期P90不变，只将有效历史池的读取权重均分。近期条件门控仍保留；8,192个查询/键参数不参与该对照的权重计算，不声称有效参数量相同。

无L摘要对照复用L0；摘要缺失时两种监督视图相同，目标函数等价，但不声称逐位重演95%/5%浮点运算。移除编号头检验的是整个适配阶段，不单独证明编号专属头优于同预算共享头。

学习读取对均匀读取的一至三月MAE差为0.078027 kW，7日块95%区间[0.029318, 0.112417]，14日块[0.031075, 0.113701]；七月7日块区间[-0.036007, 0.030082]。当前月份已用于研究探索，独立来源验证仍是后续任务。

86项单元测试通过。12个编码器、12组编号头重放，36组预测数组逐值一致，4,960项指标标量核对通过。旧预测列和锁定文件未变。编码器训练合计945.8秒，编号头20.3秒。
