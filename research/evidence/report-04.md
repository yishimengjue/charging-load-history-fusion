# 会话换算是否有收益：四组对照结果

2026-10-21。已完成176次负荷模型拟合，未重训到达模型，未新增数据或调参。

## 1. 结论

**当前可以保留紧凑的会话响应辅助方案，但不能断言“会话分解已普遍有效，旧模型
只是因为考虑内容少而放大误差”。**

紧凑换算C比直接展开到达预测D的MAE降低2.91%/6.79%，两站7/14日块区间下界均正。
然而D没有新到达响应权重，C与D的信息并不完全相同。再把同一权重给直接模型K，
比较“是否显式算好响应”的K与X：均值改善2.21%/1.80%，但JPL区间跨零。
因此没有通过事前的双站同信息增量门槛，不能将实际方案比较的收益全部归给换算。

本轮更支持“把会话知识压缩成辅助特征供直接预测器使用”，不支持“分解环节越多
越好”。紧凑C仍是已有候选，本次逐点复现了旧成绩，没有再取得一次3.47%/2.12%的
新提升。

## 2. 实际比较了什么

所有组保持原强基线M3的历史/日历/旧到达辅助输入，使用同一份原点冻结的R到达
预测、相同训练行、原已选300树P50配置、相同周度更新。新组共享J_carry，即历史
到达会话的估计剩余负荷。本次仅检验“新到达部分”的换算，不是去掉全部会话运算。

| 组别 | 原强基线之外的输入 | 输入维数 |
|---|---|---:|
| C，紧凑换算 | 新到达负荷响应 + 共用跨日负荷 | 35 |
| D，直接输入到达预测 | 完整96格到达预测 + 预测总量 + 共用跨日负荷 | 131 |
| K，提供全部换算所需数值 | D + 对应当前目标的96个历史响应权重 | 227 |
| X，显式提供换算结果 | K + 新到达负荷响应 | 228 |

权重表示“在某时段到来一次连接，平均会对当前目标贡献多少功率”，来自起报前
已完成的会话电量和持续时间。计算关系为：

`目标负荷响应 = 各时段的预测到达次数 × 对应响应权重，再求和。`

K已经掌握乘加所需全部数值；X新增的是其确定性函数，而不是新增未来观测。
完整96格的到达预测在起报时已经生成，不能与未来真实到达混淆。历史权重也按
每个训练样本自己的起报时刻重建，不能用今天才完成的会话回填过去。

C对D回答实际方案取舍，但包含额外历史会话信息和维数差异。K对X才检验同信息
条件下显式乘加表达的作用。相同树数/叶数上限不代表列数不同的模型严格等容量或
等计算量；本轮结论限于这些固定的树模型与输入表达。

## 3. 预测结果

主评价为Caltech152个完整预测日/14,592点，JPL151日/14,496点。

| 模型 | Caltech MAE / kW | JPL MAE / kW |
|---|---:|---:|
| M3，原强基线 | 8.7410 | 10.2238 |
| C，紧凑换算，复现上一轮L_R | **8.4377** | **10.0070** |
| D，直接展开到达预测 | 8.6906 | 10.7363 |
| K，到达预测 + 全部权重 | 8.7306 | 10.4184 |
| X，K + 显式换算结果 | 8.5376 | 10.2305 |

C相对D的平均改善为0.2529/0.7293 kW，即2.91%/6.79%。两站各有4/5个月改善，
不意味着所有日期都改善。C相对K的均值改善为3.35%/3.95%，其中JPL区间跨零。

同信息的K到X，MAE分别降低0.1930/0.1879 kW，即2.21%/1.80%。Caltech四个月
改善、一个月退步；JPL五个月均值改善，但按日相关性分块后的区间仍跨零，不能
用“每个月均值都好”替代稳健性证据。

X并没有超过已有紧凑C；在JPL也没有超过M3。本轮不将输入更丰富的X替代C。

| 改善差值，正数为后者较好 | 7日块95%区间 / kW | 14日块95%区间 / kW |
|---|---|---|
| Caltech，D减C | [0.0416, 0.5112] | [0.0364, 0.5224] |
| JPL，D减C | [0.1529, 1.3816] | [0.1093, 1.4570] |
| Caltech，K减X | [0.0380, 0.3583] | [0.0343, 0.3778] |
| JPL，K减X | [-0.0932, 0.4671] | [-0.1320, 0.4747] |
| Caltech，K减C | [0.0616, 0.5624] | [0.0704, 0.5794] |
| JPL，K减C | [-0.1527, 1.0211] | [-0.2230, 1.1644] |

事前门槛分别要求双站同信息X对K、或紧凑C对D和K均降低至少1%，且两种块长度
下界均正。**两项门槛均未完全通过。** 这不证明等效或换算无用，而是不足以宣布
跨站稳定增量。1%仅为继续投入门槛，不是业务收益或发表标准。

## 4. 能否解释为“原会话分解考虑少，所以误差放大”

不能。当前检验的是会话响应特征怎样帮助直接预测器，不是对旧B模型的每个组件
逐项修复后重新归因。旧B已经包含到达率、电量/功率分布、跨日补偿等多个环节，
不能仅按组件多少解释效果。

已有证据支持的范围是：

- 会话响应直接叠加还没有超过强直接基线，不能把辅助预测的改善等同于完整分解成功。
- 在当前Caltech树模型中，显式提供乘加结果有探索性同信息增量；JPL均值同向，
  稳健性证据不足。这符合“结构化表达可能更便于有限模型利用”的解释，但不是
  已经证明某个物理或行为因果机制。
- 信息不是越多越好：本轮227/228列的展开输入没有超过35列紧凑C；上一轮增加
  专门分配头也没有超过简单总量辅助。不能用“再加更多环节”作为默认改进方向。
- 旧实现确有训练与预测输入不一致、记录释放筛选等问题；本轮没有量化它们对旧B
  MAE的贡献，也未证明这些是全部原因。

因此更准确的论文表述是：**检验会话响应的显式表达是否提高直接负荷预测精度，
并区分额外信息、输入压缩与换算表达的贡献。** 目前是限定数据与模型下的证据，
不是通用新算法结论，也不是“旧方案内容少”的因果结论。

## 5. 路线决定

保留已有C作为紧凑候选，不用D/K/X替换，不再在这批已见日期调输入维数或树数。
这一轮关闭了一个归因缺口：C优于本轮直接到达展开对照，但同信息换算的双站
稳定收益尚未确立。下一阶段若推进，应固定C、M3及必要对照准备未参与选择且
口径一致的数据验证，而不是继续在原样本叠加分解模块。

全部结果仍来自已查看的2019-10至2020-02 ACN会话恒功率代理。JPL最后31格缺
真值，保持缺失并单列所有有真值格评分。不宣称实测功率或独立样本验证；响应
规则与R候选已受旧结果选择影响，重复探索和多比较风险仍在。
