# 共享决策机制：文献、验证结果与回退

日期：2026-10-22。已完成文献核查、机制定义、训练内部验证、固定7月评分和计算复核。
**本版机制未通过预设收益门槛，回退到C/S直接预测参照，不继续放宽规则求正结果。**

## 1. 文献说明什么

| 文献 | 已有做法 | 本项目不能据此声称的新意 |
|---|---|---|
| FFORMA，Montero-Manso等，2020 | 根据序列特征学习不同预测模型的组合权重 | “用特征决定权重”本身不是创新 |
| Arbitrated Ensemble for Time Series Forecasting，Cerqueira等，2017 | 用时间分块训练外预测学习模型误差，再动态组合专家 | 元学习、动态门控、按模型能力选用已有 |
| Bandara等，2020 | 对相似序列分组后训练RNN | 按相似性决定共享范围已有 |
| Montero-Manso与Hyndman，2021 | 分析局部与全局时间序列预测、分组与尺度作用 | 全局/局部结合及尺度处理已有 |

本轮阅读FFORMA作者摘要及题录、ADE开放章节3.1-3.3及实验设定、Bandara论文
arXiv摘要及期刊题录，并复用前轮全局/局部研究正文核查。不是系统综述或最新文献穷尽检索。
没有声称完整复现上述方法，也没有借用它们的性能数字。

本原型的研究着眼点是：**目标存在缺失时，仅用可见目标上的成绩决定共享，可能漏掉
不可见目标上的损失。是否应将这部分不确定性纳入共享决策？**

这是具体可检验的适配问题，但数学界限来自三角不等式，门控和有限权重选择也已有。
不能把“增加缺失风险项”直接认证为算法创新；还需证明独立增量及与已有研究的区别。

## 2. 建立的机制

保留两个专家：局部多尺度模型S、全共享模型G350。不改变专家结构或7月模型参数。

`最终预测 = 局部预测 + 共享比例 × (共享预测 - 局部预测)`

共享比例只取0、0.25、0.5、0.75、1。0表示全用局部，1表示全用共享。
按发布方编号和“168小时历史是否全部有观测”分组，共18组；历史状态在起报时已知。
这是输出组合比例的决策，不是学习该向哪个站点借训练数据，也不是物理站点因果关系。

用6月3至16日、6月17至30日两个内部窗口选择比例。
每个窗口的专家只用窗口开始前已成熟的原C标签训练，尺度也由该内部训练集计算。
查询历史仍只使用当时已成熟的参考值。内部产生6,048个预测，其中727个真值缺失。
缺失位置保留在分母，不填零、不删除；最后的门控在读取7月评分表之前冻结。

在每个内部窗口，比较某个共享比例与纯局部预测的绝对误差差。
对有真值的位置直接计算差；对没有真值的位置，用两种预测的距离作为最坏损失增加上界：

`|组合预测 - 真值| - |局部预测 - 真值| <= |组合预测 - 局部预测|`

把已知误差差与缺失位置的上界相加，再除以该组全部已起报目标数，得到历史损失差上界。
只有两个内部窗口的上界均小于0，才选用非零共享比例。优先选较保守的并列比例。
每组每个窗口还须至少7个起报日、48个已观测目标，否则回退到局部。

**该上界约束的是这些历史验证样本，不是置信区间，也不保证未来不退步。**
门控从一批内部专家迁移到7月固定专家，还存在时间变化和模型重训差异；不由上界自动解决。

### 必要对照

| 代号 | 对照内容 |
|---|---|
| C/S/L350/G0/G350 | 保留前轮直接预测、局部容量控制和全共享预测 |
| E50 | 局部与共享固定各占一半，不学习门控 |
| P | 每个编号用内部可见目标选择一个固定比例，不按历史状态分组 |
| O | 与候选相同的历史状态分组、支持门槛和双窗口检查，但去掉缺失风险项 |
| R | 本轮提出的缺失风险保守门控 |

O只忽略未知位置的损失差，不把缺失真值填成0。R与O的差异用于检验风险项本身。
P/O/R都使用同一对专家。门控额外需要内部训练，不能声称总计算量与单个S相同。

## 3. 实际预测结果

使用已获准且已查看过的Optimise Prime7月1至25日数据。
固定275个候选起报、217个实际起报、5,208个预测目标、4,775个可见真值、433个未知真值。
目标为小时边界附近的功率快照，不是ACN15分钟平均功率，不与ACN指标混合。
这是已见数据上的探索性验证，不是新盲测或跨来源验证；7月不参与本次比例选择。

| 方法 | MAE，kW | RMSE，kW |
|---|---:|---:|
| C：原直接预测 | 3.5522 | 7.8879 |
| S：局部多尺度预测 | 3.4806 | 8.0053 |
| L350：容量匹配局部预测 | 3.4862 | 8.0752 |
| G0：无显式编号全共享 | 3.6103 | 8.0932 |
| G350：带编号全共享 | 3.6009 | 8.1021 |
| E50：固定各一半 | 3.5055 | 7.9956 |
| P：按编号固定比例 | 3.4697 | 8.0126 |
| O：去掉缺失风险项 | 3.4987 | 8.0020 |
| **R：缺失风险保守门控** | **3.4806** | **8.0053** |

R在全部5,208个目标上选择共享比例0，逐点预测与S完全相同。
因此相对S的提准收益是0，而不是一项新的2.01%改善；2.01%仍来自之前S相对C的差异。
R比全共享G350低3.34%，只是回到原S的结果，不能用较弱全共享对照证明新机制成功。

按编号固定比例P的平均MAE比S低约0.31%，但对应7/14天块改善区间均跨零，
不将表中最低均值解释为新赢家，也不自动用P替换C/S。

### 为什么全部退回局部

- 18个状态组中，10组未满足两个内部窗口的样本支持要求，其中9组为历史全部完整组。
- 剩余8组中，5组在不加入风险项时也没有找到同时改善两个窗口的非零比例。
- 另外3组为编号4、5、9的历史不完整组；加入缺失位置最坏风险后，两个窗口不再都支持共享。

例：编号5使用一半共享，在第二个内部窗口有29个未知目标。可见目标累计绝对误差
下降2.2813，但未知目标可能掩盖的损失增加上界为8.4630；按全部336个目标平均后，
损失差上界为+0.0184 kW，不能据可见位置的小收益允许共享。
这些累计量是各点kW误差的数值和，不是kWh或实际能量。

O在1,224个目标上采用非零共享，P为4,008个；R为0。
R/O有1,071个预测值不同，其余非零权重位置可能因两专家预测相同而无数值差异。
新增风险项确实改变了行为，但行为改变没有带来超过S的预测收益。

### 预设门槛与边界

事前要求R相对C、S、L350、G350、E50、P、O均降低至少1% MAE，
7/14天块95%区间下界均为正，同时限制RMSE退步并要求至少5/9个编号优于S。
R没有优于S的任何编号；相对S的两个区间均为[0,0]，所以主门槛失败。
R对O仅改善0.52%，7天区间跨零；风险项的独立收益也未通过。

433个未知真值不能通过门控变成已知。本轮R与S逐点相同，因此它们在所有已起报目标上
差值仍为0；相对G350、P、O等方法的全起报改善界限仍跨零。
历史支持分组和内部窗口是固定原型选择，不是自然业务状态或最优分组的证明。

## 4. 回退与研究结论

**停止本版“二状态、双内部窗口、最坏缺失风险”的共享门控。**
不把零共享包装为成功，不放宽风险项、改分组阈值或改窗口长度来利用7月寻找正结果。
保留C为原直接预测参照、S为多尺度候选；S本身的7月增益区间跨零、RMSE更高，
也不被升级为全场景最佳。所有旧模型、标签、评分和失败证据保留。

本轮得到的具体限制是：在现有少量序列、短内部窗口和未知缺失机制下，要求最坏情形
也不受损的门控可能完全拒绝共享。本原型没有同时实现“降低共享风险”和“提高预测精度”。
这不证明所有选择性共享无效，也不能据此将未来保证补写到当前算法上。

当前不再追加同批数据的门控搜索。若以后重启方法研究，应先取得新的可靠评价条件，
或说明可检验的缺失机制/业务信息假设，使新增机制不只是减弱同一个惩罚项。
FFORMA/ADE/分组全局预测等仍需作为相关先例；没有明确差异和独立收益，不能写成已成立创新点。
