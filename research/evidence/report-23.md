# 价格与光伏链路：第一阶段执行结果

2026-10-12。执行范围：承接文献结论建立研究协议、来源准入检查和物理核算测试。
**不是新的价格实证、仿真效果研究、预注册完成或现场试验。**

## 1. 路线已经落实为什么

主问题为：在同等事前预算约束下，日照窗口优惠相对原价/全天优惠，是否改善真实光伏
利用，并满足服务和经营贡献要求？允许全天总充电不变、只是移时，不追求制造更多需求。

链路保持为 **真实价格/优惠 -> 到站与充电时空选择 -> 同边界实测电量 -> 光伏利用
-> 服务与经营贡献**。已有预测章节保留为独立信息价值问题，不把MAE改善当因果前提。

已完成：

1. 写入处理臂、随机化与表计边界、预定窗口、全资格分母、服务/收益、缺失和推断规则。
2. 增加六类最小数据表的字段要求，以及五类现有来源的机器可读证据状态。
3. 实现离线检查器，拒绝文献提及字段冒充本地数据、异站PV/负荷拼接及用户赋值配站级总表。
4. 实现仅接受手写测试数据的物理核算内核，无下载/训练/真实数据载入/现场控制入口。

协议是待运营资料补全的模板，不是已确定优惠幅度、样本量和服务门槛的真实分析计划。

## 2. 本轮补出的关键核算缺口

**同一小时有光伏和充电，不代表它们同步发生。**
手写反例：一小时先发10kWh全部外送，后充10kWh全部购电。小时`min(PV,EV)`给10kWh，
但已知方向性表计下站内PV利用是0。这证明聚合口径可高估，不是观测到公司的误差。

限定同一AC边界、无储能/V2G/其他发电/弃光/出口约束且无购电再外送：

- 站内PV利用：`S = PV发电G - 外送X`，受原生表计精度限制。
- 有其他负荷B时，充电对应的基础负荷优先归属量A满足 `max(0,S-B) <= A <= min(S,EV电量L)`。
- 核验 `G + 购电I = L + B + X`，但能量平衡通过不证明来源真实或政策因果有效。

上述A在固定细粒度PV/其他负荷路径下定义，是有条件的核算量；不是价格效应、电子
追踪或95%置信区间。若功率/连接约束已知，本界限不声称锐利。未知其他负荷、净表、
错站、缺测和窗口切过区间时拒绝精确核算，不用均摊/填零补成“实测”。

22项新测试包含729组确定性的双子区间路径枚举：真实细粒度核算值均在界限内，
粗化区间不会令这些能量界限更紧。枚举只是有限正确性测试，不是新市场样本、
普遍统计保证或原创性证明；解析理由另写在协议中。

检查器按每个来源独立评估四条用途：物理PV核算、价格到物理PV因果比较、条件会话界限
的独立计量验证、未来政策价值比较。**四条用途当前均无完整可用数据包。**
这是对现有资料的判断，不表示世界上不存在可用数据，也不是重新关闭旧预测数据。
即使将来元数据全部通过，本检查器也只允许进入人工设计复核，不自动授权数值分析。

## 4. 下一步如何执行

优先取得一个真实目标场景的最小元数据包，而不是再堆模型：

1. 运营方确认可控制的收费组件、目标站群/邻站、资格与服务要求；不在本轮现场调价。
2. 数据方确认同站EV、PV、非EV、双向并网表的边界/时区/质量，提供字典和许可说明。
3. 研究端据干预前方差和独立站群数确定W-C主比较、是否加入全天优惠、预算与非劣界值，在看真实干预结果前冻结设计，再经明确授权进入数值准入/真实比较。

若暂时只有合法会话数据，保留条件能量/可用性界限作为备选；它必须经独立细表验证，
且补审相关优化/灵活性前作，才判断是否有方法贡献。不能用会话回归替代本地价格响应。
缺同站PV就不宣称真实光伏增益，缺成本就不输出公司最优价表。
