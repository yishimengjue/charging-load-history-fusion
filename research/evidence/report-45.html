# 质量选择器回测：没有获得额外收益

2026-09-20。已完成训练期滚动预测、选择器检验和复核。**保留两个基础模型，不采用本轮质量选择器。**

## 1. 本轮检验了什么

```mermaid
flowchart LR
    A[只用当时已发生的数据] --> B[按月预测后一个月<br/>原模型 F 与 Chronos]
    B --> C[收集更早月份的预测误差]
    C --> D[用历史完整度等5项信息<br/>学习选择哪种模型]
    D --> E[在后续月份检验<br/>不回头修改规则]
    E --> F[选择器未胜出<br/>不加入当前主路线]
```

F是“历史对齐＋不完整历史训练”的本地P50模型，Chronos是固定版本的零样本P50模型。
本轮只处理2021年初始训练期：9月至12月的F预测分别由此前数据训练产生；
Chronos对8月至12月符合历史门槛的起点预测，不微调、不跨起点共享信息。

选择器只接收5项起报时可见的信息：过去7天完整度、最近1天完整度、最近观测距今多久、
已观测值中的零值比例、最长连续缺失时长。不使用编号、未来负荷、未来是否缺测或未来误差。
它从已经结束的预测日学习，决定下一天整条曲线使用F还是Chronos，不混合两个P50。

选择器用固定的线性Ridge模型，无调参。本轮是检验质量信息的一种低复杂度方案，
不是证明所有可能的质量模型都有效或都无效。

## 2. 得到了什么

8月所有编号都不足30个合格训练日起点，未降低要求训练F；10月选择器又因不足两个
历史误差月份而不准入。因此**实际选择器评价期是2021年11—12月**。

下表使用完全相同的549个编号－日期、12,908个有效观测点。误差越低越好。

| 方法 | 平均绝对误差 MAE(kW) | RMSE(kW) | 按历史负荷尺度归一后的每日平均误差 |
|---|---:|---:|---:|
| 始终使用F-P50 | 6.0672 | 13.1728 | 0.6861 |
| **始终使用Chronos-P50** | **5.1286** | **11.5002** | **0.6039** |
| 按此前总体误差选择一个模型 | 5.1286 | 11.5002 | 0.6039 |
| 依据5项历史质量信息逐日选择 | 5.4441 | 11.9922 | 0.6563 |

此前总体误差规则在两个评价月都选Chronos，因此与固定Chronos相同。
质量选择器549天中330天选Chronos、219天选F，相对上述简单规则：

- **MAE增加6.15%。**
- **事前指定的归一化每日平均误差增加8.67%。**
- 11月的归一化指标略好，但12月明显变差，未通过固定的稳定性筛选标准。

归一化指标先把每个预测日的MAE除以该日起报时已观测历史的平均功率（最低尺度1kW），
再对天等权平均，避免高负荷编号完全主导。这不是MASE，也不等于全体点MAE。
即使换用该指标，选择器也没有胜出；不能只强调它比F更好而忽略更强的Chronos基线。

## 3. 为什么不直接按完整度切换

| 检查区间 | 历史完整 | 历史不完整 |
|---|---|---|
| 此前2022年开发期 | Chronos的MAE更好 | F的MAE略好 |
| 本轮2021年11—12月回测 | Chronos的MAE更好 | Chronos的MAE也更好 |

**上一轮观察到的分组规律，没有在另一段历史中重复出现。**
这说明“缺失多就用F”目前只是特定样本中的现象，不是已经验证的稳定规则。
F的训练量、月份、负荷模式和缺失组成同时变化，不能把差异都归因于缺失。

本轮选择器尤其倾向于在历史零值较多时选F，但在历史零值比例超过75%的22个评价日，
Chronos实际MAE为0.5010kW，F为2.2366kW，选择器全部选了F。
这是事后解释失败的一个小样本片段，不用于本轮再改阈值或挑赢家。

## 4. 当前保留与下一步

**保留：**F作为本地训练与均值预测参照；Chronos作为零样本P50候选。
**不采用：**本轮五特征Ridge质量选择器，不把它应用到2022年开发期或最终期。

下一步应收敛，而不是不断给选择器加特征：

1. 优先固定F-P50与Chronos-P50为两条候选，设计最终期验证；以MAE为主，报告RMSE、
   偏差、逐编号/逐月结果和预测覆盖，F-均值作为不同统计目标的运营参照。
2. 把“最终期验证”与“预训练重叠审查”分开。即使本地封存期未看过，公开数据也可能
   曾进入基础模型预训练；仍不能声称完全未见数据上的跨域泛化。
3. 若还研究缺失机制，需要另立控制实验，在相同历史与目标上改变观测缺失，区分缺失影响
   与季节、训练样本量影响；合成缺失仅检验鲁棒性，不等于真实缺失机制。

本轮没有打开最终期。下一轮应先冻结最终验证协议，而不是自动解封。
简单模型选择本身是成熟方法；本轮也没有建立顶刊核心创新或价格因果影响。

## 5. 执行边界与验收

| 项目 | 完成情况 |
|---|---|
| 基础模型训练 | 36个固定F-P50模型；Chronos无本地训练 |
| 预测范围 | 1,683个候选编号－日期；F可预测1,098个，Chronos可预测1,377个 |
| 选择器训练 | 2个历史滚动Ridge；10月记录为历史月份不足 |
| 实际选择器评价 | 549天；476天拥有完整24个目标，其余按已有真值评分 |
| 自动测试 | 618项通过 |
| 复核 | 36个F检查点重放，2个Ridge重建，80行指标标量复算通过 |
| Chronos | 同批次安排下重新加载模型后预测逐值一致 |
| 数据边界 | 未生成2022年开发期新预测，最终期数值和质量未解封 |

历史窗口来源使用已审核加载器重建，质量特征、训练选择和指标另写标量代码复核。
这是同一执行者的交叉检查，不是外部独立审稿。
原数据、旧模型、协议、环境和已有实验结果的哈希未变；原交接压缩包未更新。

F的方法设计已受2022年开发期研究启发，因此这次历史回测虽按时点限制拟合信息，
也不能称为完全独立、事前从未接触的验证。所有结果只评价有真实观测的时段。
