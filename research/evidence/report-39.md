# C与C加TiRex预测值：结合对照未取得收益

日期：2026-10-26。已完成用户要求的一组对照及基本复核。

**结论：把TiRex-2的预测值作为辅助特征加入C，MAE增加3.93%，RMSE增加9.95%。
保留C，停止本次普通特征拼接配置。本轮没有补上论文主贡献不足的问题。**

## 1. 这组对照改变了什么

原C使用180项输入；新CT只增加一项：对应预测步的TiRex-2 P50预测值。
例如预测明日第8个小时位置时，增加TiRex对该位置的预测，而不是整条曲线的
24个输出、额外分位数或事后真值摘要。它是预测器输出特征，不是缺失真值补全。

两组保留相同的74,296个有效训练标签、行顺序、原180项输入、星期信息和
LightGBM-P50参数：300树、15叶、最小叶样本40、学习率0.05、种子42。
没有改为残差目标，没有微调TiRex，也没有选择种子或增加训练数据。

新生成3,278个历史编号日起点的TiRex曲线，每个起点只传入其自身过去168小时
信息，再按原预测步对应到训练标签。TiRex保持原固定代码/权重和推理设置。
模型没有本地训练，所以不需要为它重训本地折；外部预训练重叠风险仍未排除。
七月辅助值复用上次已保存的TiRex输出，起点、历史和预测步逐项匹配。

新增18次本地拟合：9个C重训和9个CT。**九个重训C的七月预测均与原C逐点一致**，
确认本次差异不是基线环境、样本或重训结果改变造成的。

## 2. 效果

任务仍为未来24个小时边界功率快照，不是区间电量或单车会话。
使用同275个候选编号日、217个起报编号日、5,208个输出；4,775个有真值位置评分。

| 配置 | MAE kW | RMSE kW | 相对C的MAE |
|---|---:|---:|---:|
| C，原基线及本次重训 | 3.5522 | 7.8879 | 参照 |
| **CT，C加TiRex对应步P50** | **3.6917** | **8.6729** | **增加3.93%** |
| S，已有近期信息增强候选 | 3.4806 | 8.0053 | 下降2.01% |
| TiRex-2，已有独立预测 | 4.3050 | 9.9179 | 增加21.19% |

CT比单独TiRex好，但没有超过应当比较的C，不能把前者作为新增提准成果。
CT相对已有S的MAE也增加6.06%；S保留原有区间跨零和RMSE退步限制。
CT的平均偏差从C的-1.2878变为-1.2619kW，但偏差变小不等于绝对误差变小。

| 共同评分范围 | C MAE kW | CT MAE kW | 变化 |
|---|---:|---:|---:|
| 真实零负荷，1,979点 | 1.3210 | 1.4153 | 增加7.14% |
| 普通正负荷，2,303点 | 3.4231 | 3.5320 | 增加3.18% |
| 高负荷，493点 | 13.1113 | 13.5756 | 增加3.54% |
| 全部真实正负荷，2,796点 | 5.1314 | 5.3029 | 增加3.34% |
| 排除编号4，4,673点 | 3.1782 | 3.2243 | 增加1.45% |

九个编号的MAE全部增加；25天中7天改善，18天退步，四个周段汇总均退步。
历史完整和存在缺口两组分别增加6.21%、3.44%。没有一个已报告主要分组显示
该拼接配置可以替代C。高负荷阈值沿用各编号原训练P90，不根据新结果选择。

高负荷平均低估量`mean(max(y-p,0))`从12.9889变为13.4347kW。
预设六项继续条件全部未通过，包括至少3%MAE下降、多数编号改善、去ID4仍改善，
以及RMSE、真实零负荷MAE、高负荷低估量不增加。

## 3. 核对与限制

10项新基本测试通过。74,296行辅助值按起点与预测步另用标量路径复核；18个
LightGBM检查点全部回放一致。重载TiRex后，每编号预先指定的首批共36条历史
曲线与保存输出逐值一致，不声称已二次回放全部3,278条。
主表、分组、逐一排除编号指标、日期损失及4,000次块抽样值通过复算。
原消费文件及冻结代码SHA256保持不变。这些是同一执行者的基本检查，不是外部审查。

历史TiRex推理合计约69.47秒，18个本地拟合/保存/回放约26.00秒；不含完整
准备与核对耗时，不是服务部署延迟。旧环境未修改，没有新权重下载或数值解封。

C减CT的观测MAE差为-0.1395kW，7/14日移动块的描述性95%区间分别为
[-0.2672,-0.0151]、[-0.2105,-0.0415]kW。七月已反复查看，这仍是探索性筛查。
433个未知真值不插补；全部5,208个已起报位置的差异外界限为
[-0.5058,+0.2500]kW，仍跨零，不能声称已经知道所有缺失位置上的排序。

## 4. 对研究路线意味着什么

目前两项结果分别是：独立TiRex预测不如C；将其对应步P50加到C，也没有增益。
支持停止这两个具体配置，不支持断言所有微调、隐藏表示或组合方法都无效。
本轮没有识别退步的唯一原因，也没有证明TiRex不包含任何有用信息。

**本组对照的作用是决定是否继续投入，而不是增加论文篇幅。** 当前不把
“不完整信息利用”或“TiRex加负荷预测”包装成新的论文主贡献。保留已完成基线
和负结果，不继续在本配置上添加分位数、门控、校正器或参数搜索以寻找正数。
若后续改变路线，需要新的、有数据依据的研究问题，而不只是更换模型名称。

## 5. 复现入口

冻结方案中的pytest命令原写为AMS环境；该环境没有pytest，实际使用已有TiRex
环境执行同一测试文件并通过，未给旧环境安装依赖。实际命令如下；输出目录拒绝覆盖。

```bash
bash run_tirex_python.sh -m pytest tests/test_tirex2_feature_control_v1.py -q
bash run_ams_python.sh -m src.tirex2_feature_control_v1 prepare
bash run_tirex_python.sh -m src.tirex2_feature_control_v1 extract
bash run_ams_python.sh -m src.tirex2_feature_control_v1 fit
bash run_tirex_python.sh -m src.tirex2_feature_control_v1 replay
bash run_ams_python.sh -m diagnostics.verify_tirex2_feature_control_v1
```
