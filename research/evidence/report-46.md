# 充电负荷预测：本轮实验简报

实验日期：2026-09-08；整理日期：2026-09-09。原研究目录未改动，新增实验均在独立续研目录。

## 1. 先说结论

**预测层面仍有研究空间，但当前证据不支持把“预测目标15分钟的到达数，再加入负荷模型”作为已经成立的论文核心。**

本轮“到达辅助模型也使用相同训练样本”的方案，在两个站点都没有改善平均绝对误差。原三组最终负荷模型本来就使用共同训练样本，本轮进一步对齐的是辅助模型。即使额外提供该15分钟的真实到达数，改善也很小、统计证据偏弱。因此本轮没有继续开发门控，也没有挑月份或改参数来挽救结果。

## 2. 实际做了什么

完成两个站点、7组可按既定信息规则运行的预测，以及1组单独保存的“提前知道真实到达数”诊断。后者使用未来信息，不能部署，也不是理论精度上界。

比较的是信息和训练结构的贡献，不是简单增加算法数量。所有最终负荷模型用相同训练样本；额外设置了500棵树的容量参考，以及“先预测负荷，再把预测值加入负荷模型”的两阶段对照。500棵树与200+300棵树只作粗略参考，不代表严格等容量。

MAE表示平均绝对误差，单位kW，越小越好。主评价仅保留完整的96步预测：Caltech为152天，JPL为151天。

| 可用信息范围内的方案 | Caltech MAE | JPL MAE |
|---|---:|---:|
| 历史负荷 + 日历 | 9.298 | 11.288 |
| 再加历史会话信息 | 9.073 | 11.029 |
| 再加原版到达预测特征 | 9.042 | 10.652 |
| 历史会话模型增加到500棵树 | 9.057 | 11.025 |
| 到达辅助模型保留较宽训练范围、统一更新节奏 | 9.027 | 10.887 |
| **到达辅助模型也使用相同训练样本** | **9.077** | **11.047** |
| 相同训练样本的负荷辅助预测对照 | 8.832 | 11.336 |

真实到达数诊断的MAE为9.036 / 10.913，相对历史会话模型只改善约0.037 / 0.116 kW。两站7日和14日分块检验的95%改善区间都跨过零，即仍不能排除没有改善。

原版到达特征的成绩已逐点复现，没有被改掉。它与新版本还存在训练范围、启动和更新节奏差异；本轮**不能断言旧收益完全来自更多训练数据**。负荷辅助对照也只在Caltech较好，在JPL变差，不能直接改推为稳健方案。

这些误差针对的仍是“把会话电量按恒功率摊开”的代理曲线，不是实测15分钟有功功率。研究时段此前已被查看，本轮属于探索性实验，不能作为独立验证。

## 3. 下一步建议

1. **先改善预测对象。** 优先扩展Caltech连续时段的原始测量，事先确定重复、缺口和计数器清零规则，建立带质量标记的负荷标签，而不是直接覆盖旧标签。
2. **把新假设从“一个到达数”转向“跨时段会话信息”。** 某时段负荷还来自此前到站、此刻仍在充电的车辆；仅知道该时段新来了几辆车可能不够。日前可检验预测到达轨迹的时间积累作用，日内可检验预测发出时已知的在充车辆数、已充时长和已观测功率。未知剩余需求只能估计，不能偷用最终电量或离站时间。这些方向尚未在本轮验证。
3. **保留直接负荷预测作主基线。** 下一轮仍要匹配信息、训练范围并设置容量参考，预先确定评价规则，再在未使用时段或独立场站验证。只有稳定增益成立后，才值得增加融合复杂度或论证论文创新。

当前不宜把这批结果包装成已达到顶刊水平。价格研究也尚未开展，需另行取得企业真实价表、公布/生效时间以及功率和控制记录；预测贡献不等于价格因果影响。
