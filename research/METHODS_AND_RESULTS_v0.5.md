# 历史摘要与近期序列融合的充电负荷预测

## 3 预测方法

### 3.1 预测任务与信息表示

本文研究充电负荷未来24步点预测。令x(i,j)表示计量序列i的第j个历史槽，j为1至168；y(i,h)表示第h个目标，h为1至24。OP和LCL在起报时刻t使用t−167小时至t的历史记录，目标时间戳为t＋1至t＋24小时。AMS使用区间起点标记小时电量，历史区间标签为t−168至t−1小时，第h个目标对应区间[t＋h−1, t＋h)。三种任务分别按功率快照、来源平均功率记录与小时电量的定义评价。

同一段历史可表示为按时间排列的负荷序列，也可表示为相同时段的统计分布。本文采用两个预测分支：历史统计树将滞后值和多尺度统计作为表格特征；序列融合网络将近期序列的编码与历史统计拼接。两个分支均利用近期和较长期历史，其差别在于信息表示与学习机制。网络内的历史摘要融合与网络外的输出平均分别评价；神经分支记为N，统计树记为S，其等权平均记为F。

真实零负荷与缺失记录分别处理。树模型保留缺失数值；神经模型将缺失输入填为零，并附加观测标记。OP与LCL训练保留部分目标日中已有的标签，缺失目标不进入损失；AMS采用完整训练目标日。各训练样本的24步目标窗口必须在拟合时已经结束，训练只使用当时可用标签。历史统计按每个起报时刻构造，候选参照的目标窗口必须已经结束。

### 3.2 时段对齐的历史统计

每个未来步设置三个历史参照池：最近7天相同时刻、过去28天相同星期与时刻、过去84天相同星期与时刻。候选参照来自同一计量序列。历史可用性筛选要求查询与参照在最近24小时及此前144小时分别具有至少12和72个共同观测槽，从满足条件的记录中提取该未来步对应的已观测历史目标。三个池允许重叠。

每池计算9项统计：均值、10%分位数、中位数、90%分位数、零值比例、有效参照数量、有效样本量、平均参照年龄及已观测权重质量。池内参照等权，有效样本量等于有效参照数量；已观测权重质量为该步有限标签数与池内候选数之比。分位数取排序后累计权重首次达到指定概率的标签，不作线性插值。空池的数量、有效样本量及权重质量置零，其余统计置为缺失。

三池形成27项统计。神经输入另加27项可用性标记，组成54维历史摘要。均值和负荷分位数除以该序列训练期的负荷尺度；数量及有效样本量分别除以池容量7、4、12，参照年龄分别除以7、28、84天。历史摘要保留各池的分布水平、稀疏程度和参照可用性，不包含待预测目标。

### 3.3 历史统计树与序列融合网络

普通局部树按计量序列分别训练，输入维度为180，包括168个滞后值、预测步长、4项周期对齐量和7项星期指标。周期对齐量为上周同小时、前一天同小时、7天内同小时中位数及季节参考值；季节参考值按前三项及全部历史中位数的顺序取首个有限值。历史统计树在相同训练配置下增加27项历史统计，输入维度为207。两种树采用LightGBM的0.5分位数目标。

序列分支采用TimeXer编码结构。168小时序列按长度12划分为14个片段，连同一个全局表示编码；宽度64，使用2层、4个注意力头和0.1的dropout。输入包含缩放负荷、观测标记、计量序列独热标识、log(1＋训练尺度)和星期信息。令Z为15个64维表示组成的编码结果，c为每个未来步已知的日历、序列标识、尺度及步长信息，e为24个可学习的64维步长表示。查询q的前向关系为：

@equation q = LayerNorm(W_r vec(Z) + W_c c + e)

将q与54维历史摘要m拼接，经过118至64维无偏置线性映射及层归一化，得到融合表示z：

@equation z = LayerNorm(W_q q + W_m m)

初始化时W_q为64维单位矩阵，W_m沿用线性层的默认初始化；e各分量从标准差0.02的零均值正态分布初始化。图1给出信息流。

令b为近期编码器的基础预测加上不读取摘要的残差映射；该映射读取基础预测、54维零向量和已知协变量。融合解码器d采用64至32至1维映射及GELU，末层权重和偏置初始为零。编码器训练后固定其表征，将解码器复制为各计量序列的局部头d(i)，再适配20轮。恢复原单位后的神经输出为：

@equation N = s(i) [b + d(i)(z)]

s(i)为计量序列的训练尺度。统计预测不进入该神经分支的训练输入或基础预测，只在网络外的平均步骤中使用。AMS只有一个车库，使用单个输出头。

### 3.4 训练损失与固定组合

神经分支在有历史摘要和空历史摘要两种条件下接受预测监督，两种条件共用同一次近期序列编码。空摘要同时将统计值和对应标记置零。两种条件的绝对误差损失按95%与5%加权：

@equation L = 0.95 L_actual + 0.05 L_empty

误差在观测目标上计算。各序列先按训练标签90%分位数缩放，尺度下限为1；计算损失时将缩放残差乘回尺度，保持原单位绝对误差的含义。小批量损失的分母为批起点数、全训练集平均每起点有效标签数和观测标签平均尺度的乘积。令s̄为按观测标签计数加权的训练尺度均值，则完整训练集损失等于(0.95 MAE_actual＋0.05 MAE_empty)/s̄，与两视图的加权MAE仅相差固定正比例因子。该损失作用于训练时未经截断的神经输出，不是最终F的MAE。

编码器训练80轮，局部输出头适配20轮，学习率分别为0.0003和0.001，批大小64。优化器为AdamW，权重衰减0.0001，梯度范数上限1。主要直接拼接版本对未经非负截断的神经输出计算训练损失，只在推理时将两分支负预测投影为零。设历史统计树输出为S，恢复原单位后的神经输出为N，最终预测F为：

@equation F = 0.5 max(0, S) + 0.5 max(0, N)

该组合比例在所有评价月份保持不变。它不需要按未来真实负荷选择模型。统计分支为正时，F不低于其非负预测的一半；这一输出结构会影响零负荷位置的误差。

### 3.5 配置来源

7日、28日和84日历史范围沿用历史统计实验中的固定设计，分别对应近期同小时及4周、12周同星期参照。95%与5%的监督权重来自旧条件读取结构的两个2021年12月验证段，在0%、5%和15%的空摘要损失权重中按有摘要神经预测MAE选取5%，随后沿用于直接拼接结构。80轮编码器、20轮局部输出、学习率及尺度设置沿用此前的时间顺序验证配置。50%输出组合为固定比较规则，不是为每个来源或评价月份重新求得的最优权重。当前实验单独检验摘要输入及输出平均的误差增量。

## 4 实验设置

### 4.1 数据与评价范围

Optimise Prime记为OP，目标为小时边界g前300秒内最后一条记录的功率，单位kW。所选时间戳须在同编号记录中唯一，数值须有限且非负；末条时间戳冲突时该槽缺失，不向前回退，真实零值保留。该目标是功率快照，不是小时平均功率。发布方11个编号中，9条序列进入共同模型支持范围；编号与物理站点的对应关系尚未确认。2022年一至三月共18,469个观测评分目标，七月1日至25日共4,775个。七月5,208个已起报目标中有433个未知真值。

AMS为挪威住宅车库Bl2的充电计量，目标是小时区间电量，单位kWh。本文采用2019年11月至2020年1月共有完整历史和目标窗口上的2,136个目标；当地民用时钟中的歧义或无效时刻、不完整窗口被排除。OP与AMS上述时期已用于方法探索，结果用于比较已有数据上的模型表现。

Low Carbon London记为LCL，采用居民电动汽车试验的充电记录，不是居民家庭总负荷。目标取来源在整点提供的平均功率记录，不对小时内全部采样重新求平均。时间沿用来源不带时区的时钟，物理单位换算尚未确认，误差保留为来源原始单位source_raw。后续验证采用固定的48个对象及2013年11月至2014年1月三个连续月，共88,889个观测目标；原7个未入选对象保持不变。

LCL固定方案后的验证包含4,416个日期与对象组合，其中3,807个满足起报条件，覆盖率86.21%。91,368个已起报目标中有2,479个未知。每月先拟合和核验模型，再开放该月数值并逐起点预测。原始字节和时间元数据此前已取得，此过程控制的是新时期数值的使用顺序。该验证增加同来源跨期证据。

### 4.2 时间边界与比较方法

模型按月初截止时刻拟合，之后逐日起报。OP与LCL要求168个历史槽中至少24槽有观测，最近24槽至少1槽有观测；AMS要求完整的168小时历史。OP还以至少30个满足历史条件的完整训练目标日确定月初共同支持范围，实际训练保留部分目标日的已有标签。训练尺度、摘要和局部输出头仅使用当时可用的数据。LCL下一月拟合可加入已经结束的前月记录；每月最后一个预测目标落在次月零点，若当次评价尚不可用则保持未知，不在后来补写成绩。

局部普通树与历史统计树均使用300棵树、15个叶节点、最小叶样本40及0.05学习率。共享树以全部支持序列的207维统计输入为基础，增加尺度和对象标识，对负荷变量及标签作序列尺度归一化，并按尺度加权恢复原单位误差含义；训练300棵树后继续50棵。两树组合为历史统计树与共享树的等权平均，用于比较序列分支相对另一种树预测器的增量。

LCL另设零预测和两部分分布树。后者使用207项统计特征及对象标识，分别预测零负荷概率与正负荷条件分位数，再从联合分布提取中位数。零概率分类器和15个正分位数预测器各训练150棵树，沿用既有固定配置。该对照针对充电记录的零值集中现象，不属于本文两分支融合结构。

神经模型采用42、43和44三个随机种子。每个种子分别形成两分支组合并评分，报告指标均值；不将三个种子的预测平均后重新评分。OP既有条件读取网络的组件消融用于考察该结构中的历史摘要、局部输出适配和辅助损失；直接拼接与条件读取则按共同评价位置比较。当前结构另设从训练开始移除54维历史摘要的匹配对照，实际值及其可用性标记同时置零，编码器和局部输出头均重新训练。两个视图均无摘要时，仍沿用95%与5%的同一计算路径。样本、日历、尺度、初始化、80＋20轮预算和三个种子保持不变；名义参数量不变，但摘要映射列不再激活。

### 4.3 指标与误差分解

主要指标为共同观测目标上的平均绝对误差。合并月份时累加逐点绝对误差，再除以观测目标数，不对各月MAE等权平均。相对降幅定义为比较模型MAE减去候选MAE后，再除以比较模型MAE。

成对差值先对神经种子的逐点绝对误差取平均，再按起报日累计误差差和观测数量。LCL使用完整92日起报日历，分别采用7日和14日、循环和非循环连续块，进行2,000次重采样，随机种子为20261112。新增摘要消融另固定种子20261113，在各月内部抽样，合并时按误差和与观测数求比值；OP七月采用1日至25日的完整起报日历。各次重采样均以误差差总和除以对应观测数，取2.5%和97.5%分位数。循环处理包含首尾连接假设，非循环处理在短窗口中可能产生不均匀日期权重；两类结果同时报告。

LCL按真实目标划分零负荷、普通正负荷和高负荷。高负荷阈值为每个对象当月训练正值的90%分位数。设某组包含n(g)个评分点，总体包含n个评分点，则该组对总体MAE减少量的贡献为：

@equation D(g) = [n(g) / n] [MAE_reference(g) − MAE_F(g)]

三个互斥组的贡献相加得到总体MAE变化。分组依据真实目标进行事后评分，描述已发生的误差分配。
